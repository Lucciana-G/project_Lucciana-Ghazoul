# Mamma's Bakery

Mamma's Bakery är ett skolprojekt för en enkel beställningswebbplats till ett bageri. Webbplatsen byggs med HTML, CSS och JavaScript. Innehållet är på svenska, medan logotypen behåller namnet Mamma's Bakery på engelska.

Menyn finns i "menu.json" och innehåller exempel på bröd, bakverk, desserter och sallader med ingredienser, pris i SEK och bildlänkar. Produkteer och priser är exempel skapade för projektet. Logotyp och bilder finns i "images".
