# Mamma's Bakery 🍰

Mamma's Bakery är ett skolprojekt som jag _Lucciana_ gjorde för en enkel beställningswebbplats till ett bageri. Webbplatsen byggs med HTML, CSS och JavaScript. Innehållet är på svenska, medan logotypen behåller namnet Mamma's Bakery på engelska.

Menyn finns i "menu.json" och innehåller exempel på bröd, bakverk, desserter och sallader med ingredienser, pris i SEK och bildlänkar. Produkteer och priser är exempel skapade för projektet. Logotyp och bilder finns i "images".

🧩 **Funktioner:** 🧩
_Jag använde flera JavaScript funtioner, till exempel:
. funktion för mobilmeny
. funktion för att spara historik i localStorage 
. funktion för att visa historik på skärmen
. funktion för att validera formuläret och visa felmeddelande
. funktion för att skapa show slide som loopar igenom bilder
. funktion för att hämta sortiment data från json-fil och visa på sidan
